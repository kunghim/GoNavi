# 既有可行性证据摘要

- 整理日期：2026-10-06；实验主体为 2026-10-05 的本机研究及后续用户配合。
- 目的：让 ZCode 无需读取聊天记录或私人研究目录即可理解依据与边界。
- 全部是历史实验/原型证据，GoNavi 产品尚未实现，不能填为产品验收通过。

## 1. 环境与结论

macOS 本机；独立 App Server 与自定义 ACP 实验使用 Codex CLI 0.160.0，PyCharm 内置官方入口使用 0.159.3；自定义 ACP 使用 codex-acp 2.1.1。华龙的当前受控测试目标为 GPT 配置，旧 DeepSeek 预设仅作历史记录，不能当作当前模型。

| 主题 | 观察结果 | 对开发的约束 |
| --- | --- | --- |
| 基础生命周期 | 活动/归档目录转换、取消归档、重归档最新副本、受控源删除后副本独立存在 | 原源与备份两套引用，重归档成功再替换 |
| 桌面归档观察 | 用户实际桌面归档被本地文件观察捕获，复制校验匹配 | 文件事件可作为方案基础，但一次成功不是无竞态保证 |
| 通知接入 | 独立 App Server 的另一连接收到归档等通知；现有桌面服务外部接入未完成 | 独立服务成功不等于监听现有桌面全局事件 |
| SessionEnd | 部分已加载会话归档/删除触发；未加载归档删除没有该 hook | 不能依赖一个结束 hook 覆盖所有事件；首版不安装 |
| 快速归档删除 | 一次连续归档/删除保存到最新内容，另一次受到活动写入锁约束 | 要测竞态并报告失败，不能保证任何窗口都能捕获 |
| 重启补保存 | 监听停止期间归档、源仍在时，重启补保存成功 | 只能补仍存在的源或完整候选，离线期间源已消失不能凭空补回 |
| Provider 兼容 | 有样本 resume 受理，下一轮因消息结构报 400；可读历史新建官方成功 | 找到/读取/受理/执行分开；跨 provider 默认新建 |
| 删除后利用 | 源 raw/索引/历史投影均删除后，仅靠独立材料在华龙与官方新建，虚构信息召回和续聊成功 | 副本可作为新会话资料，不等于原 ID/原列表恢复 |
| 多层 fork | 三层依赖和固定边界核对；移除整个原链后正确利用分支材料，未带入父后续新增 | 不把叶 JSONL 误作完整历史，保存固定祖先前缀 |
| 删除父引用 | 原工具拒绝删除仍被 fork 引用的祖先，后按叶到根完成受控删除 | 不能假定删除父一定自动删除所有手动分支 |
| 大型记录 | 约 587 MiB 真实归档复制和校验成功；压缩、工具对、内嵌图片作离线核对 | 不证明全历史已上传/召回，不能把耗时当所有机器指标 |
| 附件 | 内嵌图像可读；部分外部路径已失效 | 文件路径不等于附件已保存，不保证找回原分辨率 |
| 提交故障原型 | ENOSPC、三个 SIGKILL 切点、候选损坏五种结果支持保留旧副本/恢复完整候选 | 原实验脚本不是生产事务；断电/Windows/网络盘/多写入者未因此证明 |
| IDE 删除条目 | PyCharm 删除界面条目后 raw/索引仍存在，有样本仍 archived=0 | 列表移除不等于归档或物理删除，不强制备份所有“UI 删除” |
| PyCharm 续聊 | 官方和自定义华龙入口可聊天、重开；官方完整退出重开，同 ID 多轮续聊及旧信息召回通过 | 未恢复外层列表，不推定 IDEA/其他插件版本等价 |

## 2. 不要带入实现的推论

- 归档不代表文件永远不变，也不代表源被删除前一定有足够复制时间。
- 官方有生命周期事件，不代表第三方可以订阅任何桌面会话的全局实时总线。
- 相同模型名、同一个中转或协议受理，不代表旧内部上下文一定兼容。
- 一个分支文件、索引标题或一份摘要，不等于完整原始历史集合。
- 原文保留不等于能解读压缩密文，不等于模型能接收全部历史。
- 文件复制验证不等于备份事务、永久删除或终端交接已在 GoNavi 产品通过。
- 用户授权过研究测试，不等于授权未来开发者随意读取私人会话或切换全局 provider。

## 3. 官方依据及版本核验

以下链接在交接整理前已查阅（2026-10-06）；开发时按安装版本重新核对。它们解释原工具能力，不保证全部入口兼容。

- [Codex App Server](https://learn.chatgpt.com/docs/app-server)：线程方法、归档/恢复通知、读列表与分页、启动/继续。thread/list 默认可修复元数据，不能当成绝对只读观察；不要为索引 resume 所有会话。
- [Codex Hooks](https://learn.chatgpt.com/docs/hooks)：SessionEnd 覆盖条件、同步执行与 1–3 秒限制；结束事件并非所有归档删除的独立拦截点。
- [Codex 高级配置](https://learn.chatgpt.com/docs/config-file/config-advanced)：本次运行覆盖与配置来源；profile 语法有版本差异，不能直接沿用旧预设。

对原工具内部格式的适配需有版本与未知格式降级，不将公开 main 分支当成本机二进制的完整实现证明。

## 4. 原报告与跨设备边界

生命周期、provider、长历史/图片与 IDE、删除后利用/fork/故障/重启的原报告保留在研究机器，本包不携带它们的绝对路径、原始会话、认证文件、完整 CC Switch 数据库或实验工作目录。本文是可携带的实验结果摘要，不是新的产品测试报告。

另一台机器没有原报告仍可建立虚构夹具并推进实现。需要真实样本时另行取得用户对可丢弃范围与目标的明确授权，不扫描私人历史补齐证据，也不将原文或秘密提交到 Git/PR。

## 5. 交互原型的证据边界

v0.1 详情原型检查了搜索、筛选、选材料、缺依赖说明和交接预览；v0.2 接入原型检查了启用、唯一节点/页签、禁用保留、重新启用及窄窗口。全部虚构数据，没有真实安装检测、文件观察、备份、删除、剪贴板或模型请求。

因此实现必须补齐文档要求的完整过滤、真实后端状态、检测失效、材料提交、正式错误文案及能力判断。看起来能点通的原型不是通过验收的 GoNavi 功能。
